# Documentation Organization

This directory contains organized documentation for the R2-Router project.

## Structure

### Root Directory (`/`)
- **CLAUDE.md** - Main guide for Claude Code with project overview, architecture, and commands
- **EXPERIMENTAL_SETTINGS.md** - Research experimental settings and methodology
- **QUICK_REFERENCE.md** - Quick reference for demo features and recent updates

### Guides (`docs/guides/`)
Technical guides and references:
- **PREDICTOR_GUIDE.md** - How to switch between PyTorch and sklearn predictors
- **PREDICTOR_ARCHITECTURE.md** - Detailed predictor architecture documentation
- **HYPERPARAMETER_TUNING.md** - Hyperparameter tuning guide
- **CHECKPOINT_MANAGEMENT.md** - Checkpoint management strategy

### Archive (`docs/archive/`)
Historical development notes and session summaries (for reference only):

**Refactoring Notes (`archive/refactoring/`):**
- Code refactoring summaries from various development sessions
- API changes and improvements
- Baseline split and naming improvements

**Demo Session Notes (`archive/demo-sessions/`):**
- Session summaries from demo development
- Feature implementation notes (visualization, risk prediction, UI changes)
- Individual feature documentation

**Experiment Documentation (`archive/`):**
- README_EXPERIMENT.md - Experiment pipeline documentation

## Quick Navigation

**For new developers:**
→ Start with `/CLAUDE.md`

**For predictor configuration:**
→ See `docs/guides/PREDICTOR_GUIDE.md`

**For hyperparameter tuning:**
→ See `docs/guides/HYPERPARAMETER_TUNING.md`

**For historical context:**
